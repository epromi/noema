## Problem
Multiple components render empty/blank while data loads, with no visual feedback:
- **Crons.svelte**: Table renders empty (only 1 `{#if}` block, no loading guard)
- **Research.svelte**: Section is blank when no research sessions exist → no loading or empty state
- **CronSidebar.svelte**: Error state exists (`{#if crons.error}`) but no initial loading state
- **DevJobIndicator.svelte**: No loading state — countdown timer shows stale data

## Solution
Add loading skeleton indicators to each affected component:

1. **Crons.svelte**: Add `{#if loading}` → skeleton table rows (3-5 rows with pulsing placeholders) before `{#if error}` / `{#if crons.length}` 
2. **Research.svelte**: Add loading skeleton (2-3 card placeholders) + empty state ("No research sessions found")
3. **CronSidebar.svelte**: Add loading skeleton (5-8 sidebar item placeholders) before error/data states
4. **DevJobIndicator.svelte**: Add `aria-busy="true"` + subtle pulse animation while data updates

## Design constraints
- Use existing CSS variables (`var(--card)`, `var(--muted)`) for skeleton colors
- Include `prefers-reduced-motion` respect (disable pulse animation)
- Pulse animation: `@keyframes skeleton-pulse { 0%, 100% { opacity: 0.4 } 50% { opacity: 0.8 } }`
- All changes are additive (`{#if}` blocks) — no existing functionality modified

## Files to modify

- Respect `prefers-reduced-motion: reduce` in skeleton animations (app.css already has the media query)
