## Problem
AgentDetailPanel.svelte opens as a slide-out panel that acts like a modal, but:
- No focus trap: Tab key escapes to background elements
- First interactive element not focused on open
- Focus not restored to trigger element on close
- WCAG 2.4.3 Focus Order violation

## Solution
Add focus trap behavior to AgentDetailPanel.svelte:

1. **On open**: Focus the first focusable element inside the panel (close button)
2. **Focus trap**: On Tab at last focusable element → wrap to first. On Shift+Tab at first → wrap to last.
3. **On close**: Restore focus to the element that opened the panel (agent row)
4. **Escape key**: Already handled (close button), ensure focus restores

## Files to modify
- `src/lib/components/shared/AgentDetailPanel.svelte` — add focus trap logic

## Implementation notes
- Svelte 5: use `$effect()` for focus management, not `onMount`/`onDestroy`
- Use `document.activeElement` and `element.focus()` 
- Query focusable elements with: `panel.querySelectorAll('button, [href], input, select, textarea, [tabindex]:not([tabindex="-1"])')`
- Focus trap is local to this single component — no shared utility needed
- Test: open panel → Tab cycles through close button + panel content → Shift+Tab cycles backward → Escape/click close → focus returns to agent list row
