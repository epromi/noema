## Phase 3: PKG Proposals

### PKG-059: Loading States for All Tabs 🔴 HIGH

**Problem:** `LoadingSkeleton.svelte` is a well-built shared component (3 variants: card/table/metrics, aria-busy, prefers-reduced-motion) but **zero** of 18 tab components import it. Users see "No data" / "N/A" flash before real data arrives.

**Scope:** 18 components need `{#if loading}` wrappers with `LoadingSkeleton`.

**Effort:** ~2h (same pattern × 18 files)  
**Estimate:** 30-40 min  
**Impact:** Major UX improvement — eliminates "No data" flash on every tab

### PKG-060: Fix TLS Anti-Pattern (Global → Per-Request) 🔴 HIGH

**Problem:** `openclaw.ts` mutates `process.env.NODE_TLS_REJECT_UNAUTHORIZED = "0"` globally instead of using `https.Agent({ rejectUnauthorized: false })` per-request. TOCTOU race condition during async fetch window.

**Files:** `src/lib/providers/openclaw.ts` (2 locations: `gatewayApi` + `gatewayHealth`)  
**Effort:** 15 min  
**Impact:** Eliminates security anti-pattern

### PKG-061: Promise.allSettled for Resilience 🟡 MEDIUM

**Problem:** `src/lib/core/index.ts` uses `Promise.all` for 13 data fetchers. Each has internal try/catch, but if any collector re-throws unexpectedly, the entire page load fails.

**Fix:** Change to `Promise.allSettled`, merge results with fallbacks.  
**Effort:** 15 min  
**Impact:** Defense-in-depth for collector failures

### PKG-062: Extract Duplicated Utilities 🟡 MEDIUM

**Problem:** Four duplicate functions across components:
- `na()` in Overview.svelte + H1.svelte (4 lines each)
- `ottoIcon()` in OttoTimeline.svelte + Research.svelte (5 lines each)
- `proposalColor()` / `proposalPriorityColor()` in Research.svelte + ResearchProposals.svelte (5 lines each)
- `CRON_DESCRIPTIONS` 60-line inline map in Crons.svelte

**Fix:** Extract to `$lib/utils/display.ts` and `$lib/data/cron-descriptions.ts`  
**Effort:** 20 min  
**Impact:** Cleaner codebase, single source of truth

### PKG-063: SSE Reconnection & Health 🟡 MEDIUM

**Problem:** `+page.svelte` creates `EventSource` with no `onerror` handler, no reconnection backoff, no user-visible indicator of staleness.

**Fix:** Add exponential backoff reconnection, connection state tracking, and a "Live data disconnected" banner after N failures.  
**Effort:** 45 min  
**Impact:** Robustness for production use

### PKG-064: CronTimeline Naming Collision 🟢 LOW

**Problem:** Two components named `CronTimeline.svelte` — one is a shared Gantt chart (`shared/`), the other a vertical timeline (`tabs/`). Import collision avoided only by shadowing.

**Fix:** Rename `shared/CronTimeline.svelte` → `CronHealthTimeline.svelte`. Update all imports (4 files).  
**Effort:** 5 min  
**Impact:** Eliminates naming confusion

### PKG-065: Tab Bar ARIA Pattern (NC-007, NC-008, NC-009) 🔴 HIGH

**Problem:** Three keyboard accessibility blockers:
- Tab bar lacks `role="tablist"`, `role="tab"`, `aria-selected`, arrow-key navigation
- CronSidebar clickable divs have no `role="button"`, `tabindex`, or keyboard handlers
- No skip-to-main-content link

**Fix:** Add WAI-ARIA tab panel pattern to `+layout.svelte`, convert CronSidebar divs to buttons, add skip link.  
**Effort:** 1-2h  
**Impact:** Keyboard-only and screen reader users can navigate the dashboard

### PKG-066: prefers-reduced-motion for 8 Animations 🔴 HIGH

**Problem:** 8 components animate regardless of user motion preference. The global `app.css` catch-all sets `animation-duration: 0.01ms` but infinite pulsing loops may still cause vestibular discomfort.

**Fix:** Add `@media (prefers-reduced-motion: reduce) { animation: none !important; }` to each component's `<style>` block. For Svelte transitions, wrap with `{#if !$prefersReducedMotion}`.  
**Effort:** 1h  
**Components:** CronTimeline, CronSidebar, DevJobIndicator, DevPackageRow, LoadingSkeleton, Noema, ProcessorTimer, Overview
